# Data Engineering Project Template

This project builds a Databricks data lakehouse that turns Apple Health exports from several iPhone users into analytics-ready tables. It follows the Bronze → Silver → Gold medallion pattern on Apache Spark, Delta Lake and Unity Catalog.
It extends the single-file lakehouse tutorial into a multi-user pipeline. Ingesting one export.xml per participant adds problems a single file never shows: tracking which rows belong to whom, duplicate device records, mixed units, repeated full-history exports, and handling sensitive personal data.
